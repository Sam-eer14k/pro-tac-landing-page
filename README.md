# ProTac Security

Landing page for ProTac Security (Protac Inc.), a licensed California Private
Patrol Operator in Santa Maria, CA. ProTac provides armed and unarmed guards,
mobile patrol, event security, fire watch and access control across Santa Maria,
Lompoc, San Luis Obispo, Nipomo, Orcutt and the communities around them.

## What's here

```
index.html          The site. Generated by build.ps1. Open it or serve it.
site.webmanifest    Web app manifest (icons, theme colour).
assets/             Logo, favicons, hero poster and the hero background videos.
src/                Sources the site is built from. Edit these, not index.html.
wordpress-theme/    The same site as an installable WordPress theme (PHP).
docs/WIREFRAME.md   The conversion wireframe the layout was planned from.
build.ps1           Rebuilds index.html and regenerates the theme.
.nojekyll           Tells GitHub Pages to serve assets/ verbatim.
```

## View it locally

Open `index.html` in a browser. For the fonts and video to load reliably, serve
it over HTTP rather than the `file://` protocol:

```bash
# Python 3
python -m http.server 8000
# then visit http://localhost:8000
```

## Host it on GitHub Pages

1. Create an empty repository on GitHub. Don't add a README or license.
2. Push this folder to it (see below).
3. In the repo, go to **Settings > Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick
   the `main` branch and the `/ (root)` folder, and save.
5. The site goes live at `https://<your-username>.github.io/<repo-name>/` within
   a minute or two.

The folder is already a git repository with its work committed on `main`, so
you only need to add the remote and push:

```bash
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

`index.html` is at the repo root and every path in it is relative, so Pages
serves it as the home page with no extra configuration, including from a
`/<repo-name>/` sub-path.

On a public repository, anyone can read `src/`, including the `CONFIRM` and
`TODO` notes for the client. Those notes are removed from the published
`index.html` and from the WordPress theme.

## Editing the site

`index.html` is generated with all CSS and JS inlined, so do not edit it by hand.
Edit the sources instead:

```
src/_head.html      <head> contents: title, meta, favicons, fonts, structured data
src/_body.html      Page markup and all visible copy
src/css/theme.css   All styles (colour tokens at the top, from the ProTac logo)
src/js/main.js      All interaction (diagram, tabs, planner, quick check, form)
src/plates.ps1      Generates the line-art scenes in src/plates
```

Then rebuild:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

That regenerates `index.html`, and also rewrites `wordpress-theme/style.css`,
`wordpress-theme/front-page.php` and `wordpress-theme/assets/js/main.js` from the
same sources and mirrors `assets/` into the theme, so both deliverables stay in
step. `functions.php`, `index.php` and `screenshot.png` are edited in place.

## The WordPress theme

`wordpress-theme/` is a self-contained theme (`style.css`, `front-page.php`,
`functions.php`, `index.php`, `screenshot.png`, `assets/`). GitHub Pages ignores
it because Pages does not run PHP. To use it, copy the folder into a WordPress
install under `wp-content/themes/`, activate it, then set a static front page
under **Settings > Reading**.

In WordPress the request form posts to `admin-post.php` and emails the lead with
`wp_mail`. Requests go to the site admin email until an address is entered under
**Settings > General > ProTac quote email**. Make sure the host can send mail
(an SMTP plugin is the usual fix if it can't). The PHP has not been run yet,
because the build PC has no PHP, so test the form on a staging site first.

## Notes

- **The form on GitHub Pages.** The static site has no server and ProTac
  publishes no email address, so the form can't deliver a request yet. It asks
  the visitor to call (805) 938-9100 and copies their details. Set `$LeadEmail`
  in `build.ps1` and it will open the visitor's email app instead. The
  "Got it. We'll call you back." screen only appears after WordPress confirms
  the email went out. Open `index.html?formpreview=1` to see that screen without
  sending anything.
- The hero background video is a 1600px, 3.2 MB re-encode of the 12 MB 2560px
  original (`assets/video/protac-hero.mp4`), with an 854px, 1.2 MB version for
  phones (`protac-hero-mobile.mp4`). Both are well within GitHub's limits.
- **Van photo.** Save it as `assets/images/protac-van.jpg` (or `.webp` / `.png`)
  and run the build. About switches to the photo layout with tilt, gold frame and
  badge. Until then, About shows no image.
- Section visuals are inline SVG line art. The coverage planner counts
  officer-hours only, because ProTac's prices are unknown. Keep dollar figures
  out of it unless ProTac supplies them.
- Reviews are quoted from BBB as written, with BBB's 5-star ratings and dates.
  The page uses the B D. and Leonard Z reviews. BBB also has a 5-star review from
  Heart and Sugar events.
- Fonts (Chakra Petch, Hanken Grotesk, IBM Plex Mono) load from Google Fonts, so
  the live site needs an internet connection for the intended typography.
- The supplied logo has a near-black wordmark that disappears on navy, so it sits
  unchanged on a white plate in the header and footer.
- Favicons (`favicon.ico`, 16/32 px, Apple touch icon, 192/512 px) and the hero
  shield (`protac-monogram.png`) come from the supplied Pro Tac Favicon.png.
- Motion respects `prefers-reduced-motion`: the custom cursor, magnetic buttons,
  hero video, word reveal, counters, ticker, hero panel cycling and scroll reveals are
  off or static, and numbers show their final values.
- protacsecurity.com blocked automated access during the build. Facts come from
  ProTac's BBB and Alignable profiles, listed in `docs/WIREFRAME.md`.

answer, then run `build.ps1`:

1. Patrol van photo (see Notes).
2. Founding year: BBB says 2015, Alignable says 2014. The page uses 2015.
3. The spelling of Sonny Brasile (Alignable's spelling), and approval to mention him.
4. Approval to name System of a Down and Linkin Park in Bruce Thompson's bio.
5. Hero diagram captions, service bullets and ideal-for tags, and the quick check
   and finder recommendations: have ProTac confirm they match how it works.
6. FAQ answers on minimum shift length and insurance.
7. An inbox for form requests (`$LeadEmail`), or use the WordPress theme.
8. Privacy and terms pages, linked from the footer.
9. All copy compared against protacsecurity.com.
